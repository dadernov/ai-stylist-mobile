# AI Стилист — что нужно для полной автономности (работа 24/7 без разработчика)

**Дата:** 03.06.2026
**Кому:** инвестор / заказчик
**Суть:** перечень того, что требуется, чтобы приложение работало для пользователей круглосуточно и **не зависело от компьютера и присутствия разработчика**.

---

## 1. Где мы сейчас

Приложение полностью разработано и работает, но запускается в **режиме разработки**:
приложение раздаётся с компьютера разработчика через временный канал (туннель). Это значит, что
**оно доступно только пока компьютер разработчика включён, запущен туннель и есть стабильный интернет.**

Это нормальная стадия для разработки и демонстраций, но не подходит для боевой эксплуатации.
Чтобы выполнить требование «работает 24/7 без разработчика», нужно закрыть три блока ниже.

Система состоит из двух частей, их нужно выводить в автономность отдельно:
- **Мобильное приложение** (то, что на телефоне у пользователя);
- **AI-сервер** (облачные «мозги»: примерка, распознавание вещей, рекомендации).

---

## 2. Блок А. Мобильное приложение — раздача без компьютера разработчика

**Проблема:** сейчас приложение «живёт» на компьютере разработчика.

**Решение:** собрать самостоятельную версию приложения и раздавать её через официальные каналы.
После этого приложение устанавливается на телефон как обычное и работает само — компьютер разработчика не нужен.
Обновления при этом доставляются пользователям «по воздуху», без переустановки.

**Что для этого требуется оформить:**

| Платформа | Что нужно | Стоимость | Зачем |
|---|---|---|---|
| **iPhone (iOS)** | Аккаунт **Apple Developer Program** | **$99 / год** | Обязательное требование Apple. Без него установить приложение на iPhone и раздавать тестерам/в App Store невозможно. |
| **Android** (опционально) | Аккаунт **Google Play Developer** | **$25 единоразово** | Для раздачи на Android. Можно и бесплатно — прямой ссылкой на установочный файл. |

**Как будет раздаваться заказчику/тестерам после оформления:** через **TestFlight** (iOS) —
человеку приходит приглашение по почте, он ставит приложение и пользуется где угодно. До 10 000 тестеров.
Это стандартный отраслевой способ показывать продукт до публикации в App Store.

---

## 3. Блок Б. AI-сервер — надёжность 24/7

**Хорошая новость:** сервер уже вынесен в облако (отдельный VPS) и работает **независимо от компьютера разработчика**,
с автоматическим перезапуском сервиса. То есть «мозги» приложения уже крутятся в облаке.

**Что нужно закрыть, чтобы это было по-настоящему надёжно и не зависело от одного человека:**

| Риск сейчас | Чем грозит | Что сделать |
|---|---|---|
| Сервер и ключи оформлены на личные аккаунты разработчика | Зависимость от одного человека; при его уходе доступ теряется | **Переоформить хостинг, домен и ключи на аккаунты компании** |
| Оплата хостинга вручную / на личную карту | Забыли продлить — сервис лёг | Привязать **корпоративную карту с автопродлением** |
| Внешний AI-сервис (генерация образов) тарифицируется по использованию | Закончился баланс — генерация перестаёт работать | Привязать **биллинг компании + оповещение о низком балансе** |
| Нет мониторинга | Сервер упадёт ночью — никто не узнает | Поставить **uptime-мониторинг с уведомлениями** (есть бесплатные сервисы) |
| Доступ к серверу только с российских IP, по «голому» IP-адресу без HTTPS | Часть пользователей не достучится; не соответствует требованиям магазинов | Подключить **домен + HTTPS**, пересмотреть сетевые ограничения |

---

## 4. Блок В. Передача владения (ключевое для «независимости от меня»)

Чтобы продукт не зависел от конкретного разработчика, все ресурсы должны принадлежать **компании**, а не личным аккаунтам:

- Аккаунт **Apple Developer** — оформить на компанию (Organization), не на личный Apple ID.
- Аккаунт хостинга (VPS) — на почту/реквизиты компании.
- **Домен** — на компанию.
- Аккаунт внешнего AI-сервиса генерации и его **API-ключ** — на компанию, с корпоративным биллингом.
- Репозиторий с кодом — в организации компании.

После этого любой разработчик может подхватить проект, а доступы не «уходят» вместе с человеком.

---

## 5. Что требуется от инвестора — короткий список

1. **Apple Developer Program — $99/год** *(обязательно для iPhone)*.
2. **Google Play — $25 единоразово** *(опционально, если нужен Android)*.
3. **Домен — ~$10–15/год** *(для нормального адреса сервера и HTTPS)*.
4. **Оплата хостинга (VPS)** — уже используется; перевести на корпоративную карту с автопродлением *(ориентировочно несколько $/мес, по тарифу)*.
5. **Биллинг внешнего AI-сервиса генерации** — на компанию, оплата по факту использования.
6. **Переоформление всех аккаунтов на компанию** — организационное, без затрат.

### Ориентир по деньгам

| Статья | Тип | Сумма |
|---|---|---|
| Apple Developer | ежегодно | $99 / год |
| Google Play (если нужен Android) | разово | $25 |
| Домен | ежегодно | ~$10–15 / год |
| Хостинг VPS | ежемесячно | по тарифу (немного) |
| AI-генерация (внешний сервис) | по использованию | зависит от числа примерок |
| Мониторинг | — | бесплатно (free-tier) |

Главная и обязательная позиция — **Apple Developer ($99/год)**: именно она снимает зависимость от компьютера разработчика для iPhone.

## 6. Что уже сделано (не требует затрат)

- Приложение полностью разработано и протестировано.
- AI-сервер вынесен в облако, работает с автоматическим перезапуском.
- Проект уже технически подготовлен к автономной сборке и доставке обновлений «по воздуху» —
  как только появятся аккаунты, выпуск делается силами разработчика без дополнительной разработки.

## 7. Итог

Чтобы приложение работало 24/7 без разработчика, нужно закрыть три вещи:
1. **Раздача приложения** → аккаунт Apple Developer ($99/год) + автономная сборка.
2. **Надёжность сервера** → перевод хостинга/ключей/домена на компанию + мониторинг и автоплатежи.
3. **Владение** → все аккаунты на компанию.

После этого: приложение установлено у пользователей, сервер работает в облаке, обновления прилетают сами —
**присутствие разработчика и его компьютер не нужны.**
