# AI Стилист (MVP)

Стартовый кроссплатформенный мобильный MVP на `Expo + React Native + TypeScript`.

## Что реализовано сейчас

- Русскоязычный минималистичный интерфейс.
- Onboarding-экран с объяснением логики приложения.
- Нижняя навигация (5 экранов):
  - `Гардероб`
  - `Конструктор образов`
  - `Рекомендации`
  - `Избранное`
  - `Профиль`
- Основа первой части ТЗ:
  - Карточки вещей в гардеробе.
  - Отображение результата AI-анализа (тип, цвет, сезон, паттерн).
  - Кнопка ручного редактирования (UI-заготовка).
  - Пресеты стиля и мероприятия.
  - Блок погоды и генерация 3-5 образов (на мок-данных).

## Запуск

1. Установить зависимости:

```bash
npm install
```

2. Запустить проект:

```bash
npm run start
```

3. Открыть в эмуляторе/на устройстве:

```bash
npm run ios
npm run android
```

## Конфиг AI API

По умолчанию клиент использует `http://193.233.250.130:8000`.

Чтобы переопределить адрес AI-сервера, укажи переменную окружения:

```bash
EXPO_PUBLIC_AI_BASE_URL=http://<your-host>:8000
```

## Как обычно идет разработка iOS/Android

1. Product discovery
   - Формализуются сценарии пользователя и MVP-функции.
2. UX/UI
   - Создаются вайрфреймы, затем UI-kit и интерактивный прототип.
3. Архитектура
   - Выбор стека (нативно или кроссплатформа), модель данных, API-контракты.
4. Разработка MVP
   - Экранная логика, состояние, интеграция backend, базовая аналитика.
5. Интеграция AI
   - Отдельный сервис/модуль для CV и рекомендаций, валидация качества.
6. Тестирование
   - Unit, интеграционные, ручное тестирование на реальных девайсах iOS/Android.
7. Release
   - Сборка релизов, публикация в App Store / Google Play, мониторинг ошибок.

## Почему сейчас выбран Expo

- Быстрое MVP для iOS и Android из одного кода.
- Можно параллельно валидировать продукт и дизайн.
- Позже при необходимости можно перейти на более глубокую нативную интеграцию.
